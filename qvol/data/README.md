# Data

`takaishi/` is an unmodified copy of the data published by Tetsuya Takaishi in
https://github.com/takaishi-physics/QCL-volatility, released under the GNU General Public
License v3 (full text in `takaishi/LICENSE`).

| File | Contents |
| --- | --- |
| `data-ystand` | Bitcoin daily realized volatility (rescaled by the author) |
| `data-rstand` | Bitcoin daily returns (rescaled by the author) |
| `data-predicted-volatility` | Volatility generated by the author's trained circuit (50,000 steps) |
| `data-predicted-return` | Returns generated by the author's trained circuit (50,000 steps) |

Source paper: T. Takaishi, Quantum Circuit Learning for Volatility Modeling: Multifractal
Analysis of Realized Volatility Time Series, Fractal and Fractional 10(7):442 (2026).

To re-download a fresh copy instead, delete `takaishi/` and run `bash scripts/get_data.sh`.
