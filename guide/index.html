Guide

This guide shows how to run the quantum volatility forecaster, reproduce its results and read the evidence behind them.

  • Quickstart: install and run a first forecast in four commands.
  • Usage: run the studies, verify them and draw the plots.
  • Configuration: config files and the CSV format for your own data.
  • FAQ and limits: what the results do and do not show.

The research record itself lives in doc/: the plan, one protocol and one results note per study.
