# Guide

This guide shows how to run the quantum volatility forecaster, reproduce its results and read the evidence behind them.

- [Quickstart](quickstart): install and run a first forecast in four commands.
- [Usage](usage): run the studies, verify them and draw the plots.
- [Configuration](configuration): config files and the CSV format for your own data.
- [FAQ and limits](faq): what the results do and do not show.

The research record itself lives in [`doc/`](https://github.com/moneytosms/qcproj/tree/main/doc): the plan, one protocol and one results note per study.
